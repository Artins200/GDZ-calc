Дроби пишите в скобках: (x + 3)/2 ≥ (2x − 1)/3. Систему — каждое неравенство с новой строки.

Введите функцию и нажмите «Построить». Перетаскивайте поле для сдвига, касайтесь для координат.

Поддерживаются выражения (sin(x), sqrt(x)), кусочные записи «кусочно: x < 0: -x; x >= 0: x», несколько графиков, уравнения ax + by = c, полуплоскости y < kx + b, точки x,y и линия через точки. Масштаб: кнопками или колёсиком; сдвиг — перетаскиванием.

Системы счисления
Задача по информатике (с «Дано»)
Формулы
  1. 1 байт = 8 бит; 1 КБ = 1024 Б; 1 МБ = 1024 КБ; 1 ГБ = 1024 МБ; 1 ТБ = 1024 ГБ
  2. N = 2^i — сколько вариантов кодируют i бит; i = log₂N
  3. N = K^i — мощность алфавита K и вес символа i
  4. I = K · i — объём сообщения (символы × бит на символ)
  5. t = I / V — время передачи при скорости V
Быстрый калькулятор
Задача по геометрии (с «Дано»)
Формулы 7—9 класса (Атанасян)
  1. Сумма углов треугольника: ∠A + ∠B + ∠C = 180°; смежные углы: 180°
  2. Пифагор: c² = a² + b²; sin A = a/c; cos A = b/c
  3. S△ = ½ah; S△ = √(p(p−a)(p−b)(p−c)) — Герон
  4. Окружность: C = 2πr; S = πr²; дуга и сектор: α/360
  5. Теоремы синусов a/sin A = 2R и косинусов a² = b² + c² − 2bc·cos A
  6. Площади: S▱ = ah; Sтрап = ½(a+b)h; Sромба = ½d₁d₂
  7. Объёмы: V = abc; Vцил = πr²h; Vкон = πr²h/3; Vшара = 4/3πr³
