# GDZ-calc — калькулятор по учебнику алгебры 7 класса

Интерактивный справочник-калькулятор, собранный по учебнику
**«Математика. Алгебра. 7 класс»** (Ю. Н. Макарычев, Н. Г. Миндюк, К. И. Нешков,
С. Б. Суворова — М.: Просвещение, 2024, 255 с.).

Из учебника извлечено **всё**: определения, формулы, тождества, правила, свойства
степеней, ФСУ, алгоритмы решения уравнений и систем, числовые промежутки.
Каждая карточка посчитана, проверена и снабжена ссылкой на параграф и страницу.

Плюс отдельный решатель текстовых задач — **детерминированный парсер шаблонов,
не нейросеть**: он узнаёт задачу по словам и единицам измерения и выдаёт готовое
пошаговое решение.

---

## Запуск

```bash
cd GDZ-calc
npm start          # http://localhost:4173
npm test           # 57 проверок: формулы, тождества, задачи
```

Сервер `server.mjs` не требует зависимостей (только стандартная библиотека Node),
слушает `0.0.0.0`, порт берётся из `PORT` (по умолчанию `4173`).

### `js/mathcore.js` — движок

* `compile`/`evaluate` — разбор выражения без `eval`: подразумеваемое умножение
  (`2a`, `3(x+1)`), запятая как десятичный разделитель, `−/×/÷/:`, `|x|`,
  `sqrt`, `abs`, `PI`, степени `^`.
* `fmt`, `fmtSmart`, `fmtPlain`, `asFraction` — вывод: `6,3`, `1/3`, `0,333…`.
* `solveEquation` — линейные уравнения точно, остальные — численно (бисекция).
* `solveSystem` — системы двух линейных уравнений методом Крамера.
* `Poly` — символьные многочлены: `expandExpression`, `polyToText` (порядок
  слагаемых как в учебнике), `checkIdentity` (символьно, с численной проверкой
  как запасным вариантом), `factorExpression` (общий множитель, `a²−b²`,
  `a³±b³`, полный квадрат, теорема Виета, группировка).
* `solveFormula(eq, unknown, known)` — выражает любую переменную из формулы
  (обратная задача: дано `S` и `b`, найти `a`).
* `substituteText` — подстановка чисел в формулу с человеческой записью.

### `js/formulas.js` — как добавить формулу

Каждая карточка — обычный объект в массиве `RAW`:

```js
{
  id: 'rect_area',           // уникальный, используется в ссылках
  ch: 'ch1', sec: '§ 1, п. 2', page: 12,
  kind: 'formula',           // formula | identity | rule | interval
  title: 'Площадь прямоугольника',
  display: 'S = a·b',        // как в учебнике
  eq: 'S = a*b',             // машинная запись для вычислителя
  vars: [
    ['a', 'длина a', 'см', 6],
    ['b', 'ширина b', 'см', 5],
    ['S', 'площадь S', 'см²', null],
  ],
  find: 'S',                 // что ищем по умолчанию (null — для правил)
  dom: [0, 1e6],             // область поиска неизвестной
  desc: '…', keywords: ['площад', 'прямоугольник'],
  example: '…',
}
```

`FORMULAS` собирается из `RAW`, `STATS` считает итоги, `formulaSearch(q)`
ищет по названию, записи, описанию и ключевым словам, `FORMULA_BY_ID` —
быстрый доступ по id. Тест `tests/smoke.mjs` автоматически проверяет, что
**каждая** формула решается при значениях по умолчанию, а каждое тождество
подтверждается символьно, — поэтому новая карточка сразу проходит проверку
или явно сообщает об ошибке.

Тождества (`kind: 'identity'`) задаются через `eq: 'L = R'`; в интерфейсе у них
две кнопки: «проверить» (подстановка чисел) и «раскрыть обе части» (символьное
раскрытие через `checkIdentity`).

### `js/intervals.js` — промежутки и рисунок

`parseInterval('[-2; 5)')` понимает:

* запись промежутка: `[a; b]`, `(a; b)`, `[a; b)`, `(a; b]`, `(-∞; b]`, `[a; +∞)`;
* неравенства: `x ⩾ 2`, `x < 3`, `x ≤ −1`, `x > 0`;
* двойные неравенства: `−2 ≤ x < 5`, `1 < x ≤ 4`;
* бесконечности в любой записи: `+∞`, `-∞`, `∞`, `бесконечность`.

`intersect(a, b)` и `union(a, b)` находят пересечение и объединение (для
непересекающихся промежутков объединение возвращается как два отрезка).

`numberLineSVG([{ interval, label, color }])` рисует числовую прямую в стиле
учебника (рис. 10—16): ось со стрелкой, засечки, **закрашенный кружок** для
включённого конца и **светлый кружок** для выключенного, выделенная линия над
осью и стрелки в бесконечность. Несколько промежутков рисуются на одной оси
разными цветами — видно пересечение. Это SVG без зависимостей: масштабируется,
печатается и работает в тёмной теме браузера.

### `js/tasks.js` — как работает решатель задач

Это **не нейросеть**. Текст приводится к нижнему регистру, ё→е, дефисы и
дроби нормализуются, числа извлекаются вместе с единицами (`км/ч`, `м²`, `%`,
`руб`, `ч`, `мин`). Затем каждый из 46 шаблонов получает оценку:

* совпадение ключевых слов (`скорост`, `навстречу`, `скидк`, `кратн`…);
* совпадение единиц измерения (нашлись ли `км/ч`, проценты, площадь);
* обязательные условия (`require`) и запреты (`forbid`) — именно они
  разводят похожие задачи: «на скорость» против «на дроби», задача о течении
  против задачи о встречном движении, проценты от числа против скидки.

Тонкости, которые уже учтены в парсере:

* единица измерения может стоять только у последнего числа списка — «скорости
  12 и 8 км/ч» понимается как две скорости;
* числа внутри вопроса («сколько деталей в час?») не считаются данными;
* «за сколько часов» переключает шаблон работы на поиск времени, «сколько в
  час» — на поиск производительности;
* запятая внутри числа (`6,5`) не путается с разделителем уравнений в системе;
* единицы ответа наследуются из условия: `9,5 м × 4 м` → `38 м²`, а не `38 см²`.

Побеждает шаблон с наибольшей оценкой; разница в баллах показывается
пользователю («почему так») вместе с таблицей похожих шаблонов. Если ни один
шаблон не набрал минимума, включается запасной разбор: калькулятор всё равно
пытается найти уравнение или вычислить выражение и честно говорит, что шаблон
не распознан.

`solveTask(text)` возвращает:

```js
{
  ok, pattern, matched, confidence,
  answer, unknown, steps, notes, why,
  inputs,            // числа, которые распознаны в задаче
  whatIf,            // готовые варианты «а что если другое число»
  candidates,        // похожие шаблоны с баллами
  related,           // формулы учебника, по которым решено
  draw,              // SVG-рисунок, если это промежуток или чертёж
}
```

`recomputeWith(solution, { s: 780 })` пересчитывает ответ с новыми числами,
сохраняя те же шаги. В интерфейсе это живые поля: меняете число — ответ
обновляется сразу, без повторного ввода задачи.

#### Как добавить свой шаблон

Шаблоны регистрируются через `addRule` в `js/tasks.js`:

```js
addRule({
  id: 'my_pattern',
  name: 'Мой шаблон',
  run(ctx) {
    // ctx.text — нормализованный текст, ctx.nums — числа с единицами,
    // ctx.has(/…/) — поиск по тексту, ctx.qHas(/…/) — только в вопросе,
    // ctx.byUnit('км/ч') — значения с этой единицей.
    if (!ctx.has(/ключев/)) return null;          // не наш случай
    if (ctx.has(/исключ/)) return null;           // отсекаем ложные совпадения
    const v = ctx.byUnit('км/ч')[0];
    const t = ctx.byUnit('ч')[0];
    if (v == null || t == null) return null;

    return buildResult(12, {                     // 12 — вес шаблона в конкурсе
      matched: 'Мой шаблон',
      why: ['найдены скорость и время', 'вопрос о пути'],
      inputs: { v, t },                          // сюда попадут поля «а что если»
      unknown: 's',
      formulaIds: ['speed_path'],                // карточки из formulas.js
      compute: (vals) => ({
        answer: `${fmt(vals.v * vals.t)} км`,
        unit: 'км',
        steps: ['s = v · t', `s = ${fmt(vals.v)} · ${fmt(vals.t)}`, `s = ${fmt(vals.v * vals.t)} км`],
      }),
    });
  },
});
```

Правила:
* верните `null`, если задача не подходит — так работает конкуренция шаблонов;
* `compute(vals)` вызывается заново при пересчёте («а что если»), поэтому все
  вычисления должны быть внутри него, а `vals` — использовать вместо
  захваченных чисел;
* `score` (первый аргумент `buildResult`) — вес: сильные признаки ставьте
  15—25, слабые 6—12;
* если нужен рисунок, положите готовый SVG-строкой в `draw` (например,
  `numberLineSVG(...)` из `js/intervals.js`).

Шаблон сразу попадает в `RULES`, в `RULE_NAMES`, в счётчик `RULE_COUNT` и в
список на вкладке «Справка». Добавьте пример в `TASK_EXAMPLES` — он станет
кнопкой в интерфейсе и будет проверяться тестом.

## Проверки

`npm test` (57 проверок) подтверждает:

* все 185 карточек загружаются и имеют корректные поля;
* каждая из 81 формулы решается при значениях по умолчанию;
* каждое из 60 тождеств подтверждается символьно;
* все 9 промежутков разбираются и рисуются;
* пересечение/объединение дают верные границы и включённость концов;
* все 20 примеров задач распознаются, и ответы совпадают с ответами учебника:
  № 190 → 1,08 км, № 277 → 60 км/ч, № 251 → 6,3, № 257 → 6 банок,
  № 175 → 20 км/ч, № 374 → 310 м/с, № 1126 → 2 ч, № 555 → площадь × 9,
  15 % от 240 → 36, скидка 25 % от 2400 → 1800;
* «а что если» пересчитывает ответ (390 км / 6,5 ч → при 780 км получается 120 км/ч);
* **18 задач не из учебника** решаются теми же шаблонами (движение, дроби вида
  `3/7`, проценты и скидки, работа, течение, встречное движение, площади и
  объёмы, системы уравнений, ФСУ) — и похожие шаблоны не путаются между собой
  (скорость ≠ дробь);
* неизвестная задача не падает, а даёт подсказки.

## Соглашения

* Десятичный разделитель на вводе — и запятая, и точка; на выводе — запятая.
* Минус в формулах — типографский `−`, в машинной записи — обычный `-`.
* Страницы указаны по бумажному учебнику; PDF-страница = страница + 1.
* Всё считается локально в браузере: ни запросов, ни зависимостей, ни
  отправки условий задач куда-либо.
