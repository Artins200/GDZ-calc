# GDZ-calc — калькулятор по учебнику алгебры 7 класса

Интерактивный справочник-калькулятор, собранный по учебнику
**«Математика. Алгебра. 7 класс»** (Ю. Н. Макарычев, Н. Г. Миндюк, К. И. Нешков,
С. Б. Суворова — М.: Просвещение, 2024, 255 с.).

Из учебника извлечено **всё**: определения, формулы, тождества, правила, свойства
степеней, ФСУ, алгоритмы решения уравнений и систем, числовые промежутки.
Каждая карточка посчитана, проверена и снабжена ссылкой на параграф и страницу.

Плюс **«Смета»** — отдельный открытый файл-движок `smeta.html` (MIT): таблица с
переменными и выражениями, столбчатая диаграмма, стрелки «что от чего зависит»
и ответы на вопросы словами («сколько сделали в первый день?»).

---

## Запуск

```bash
cd GDZ-calc
npm start          # http://localhost:4173
npm test           # все 86 проверок: ядро (55) + смета (27) + интеграция в jsdom (4)
npm run test:core      # только ядро (55)
npm run test:smeta     # только смета (27)
npm run test:browser   # только интеграционный прогон (4)
```

Сервер `server.mjs` не требует зависимостей (только стандартная библиотека Node),
слушает `0.0.0.0`, порт берётся из `PORT` (по умолчанию `4173`).
Границы (честно): отдаёт только файлы внутри каталога проекта (симлинки
разрешаются и проверяются — выйти за пределы нельзя), только `GET`/`HEAD`,
без `Range` и кеша. Это локальное превью, а не прод-сервер. Никаких `Access-Control-*`
заголовков — приложение везде работает с одного origin (и в APK).

## Android-приложение (APK)

В репозитории лежит готовый **`GDZ-calc.apk`** — то же самое приложение одним
файлом, полностью офлайн:

* `minSdkVersion 21` (Android 5.0+), `targetSdkVersion 34`;
* **нет разрешения INTERNET** — всё содержимое (HTML, CSS, JS, формулы)
  упаковано в `assets/www` внутри APK, сеть запрещена и в манифесте, и в
  `WebSettings`;
* подпись v1 + v2 + v3 (debug-ключ, для личной установки достаточно);
* размер ~205 КБ (был ~530 КБ: убрали решатель задач и модель-диспетчер), иконка во всех плотностях + адаптивная.
* внутри — и `smeta.html`: вкладка «Смета» работает и в APK (iframe на том же файле).

Установка: скинуть файл на телефон и открыть (нужно разрешить установку из
неизвестных источников), либо `adb install GDZ-calc.apk`.

### Как собрано (без Android Studio и Gradle)

```bash
./android/build-apk.sh      # → ./GDZ-calc.apk
```

Нужен только JRE (`java`) и `curl`; JDK и Android SDK не требуются —
скрипт сам скачивает инструменты в `android/tools/`:

| Шаг | Инструмент |
|---|---|
| ресурсы | `aapt2` (готовый Linux-бинарник из npm-пакета `aaptjs3`) |
| Java → байткод | Eclipse ECJ (`ecj.jar`, работает на голом JRE) |
| байткод → dex | R8/D8 (`d8.jar`) |
| выравнивание | `android/tools/zipalign.py` (свой, без SDK) |
| подпись | `apksigner.jar` + debug-keystore |

Почему WebView, а не нативный UI: весь калькулятор — это ES-модули и SVG,
и они уже отлажены в браузере. Обёртка добавляет только то, чего нет в
браузере: иконку, запуск с рабочего стола, офлайн-режим и запрет сети.

Техническая деталь: `file:///android_asset/...` **не работает** с
`<script type="module">` (импорты блокируются как CORS). Поэтому
`MainActivity` отдаёт ассеты через виртуальный origin
`https://appassets.androidplatform.net/` — тот же приём, что в
`androidx.webkit.WebViewAssetLoader`, но без зависимостей.

## Что внутри

Всё приложение — в одной тёмной теме: клавиатура, неравенства, смета,
справочник. Никаких белых листов и «переключений стиля» по дороге.

| Где | Что делает |
|---|---|
| **Счёт** (главный экран) | Цифры, `+ − × ÷`, проценты, `±`, степень, корень, π. Считает сразу, как обычный калькулятор. Работает и физическая клавиатура: цифры, `Enter`/`=`, `Backspace`, `Esc` |
| **Галочка «Считать в столбик»** (прямо под клавиатурой) | Включили — под калькулятором появляется запись в столбик: сложение, вычитание и умножение с «лесенкой» и чертой, как в тетради. Настройку не нужно искать в шестерёнке |
| **Неравенства** | Линейные, двойные, с модулем, с дробями, системы, а также `A ∩ B`, `A ∪ B`, `A \ B`. Ответ — промежутком, с рисунком прямой и шагами решения |
| **Геометрия** | Вкладка с калькуляторами фигур и тел и отдельный «Идеальный треугольник»: по трём сторонам, двум сторонам и углу или стороне и двум углам строится SVG-чертёж с подписанными сторонами и углами (можно скачать) |
| **Информатика** | Единицы информации (бит/байт/КБ/МБ/ГБ), `N = K^i`, `I = K·i`, системы счисления, «Дано — Найти — Решение» по типовым задачам |
| **Графики** | Построение графиков функций на canvas: пресеты и произвольный ввод |
| **Смета** | Таблица с переменными (значение — любое выражение), ячейки считаются выражениями, «Всего»/«Итого», столбчатая диаграмма, стрелки «что от чего зависит» и **вопросы словами** («сколько сделали в первый день?», «какая численность?»). Открытый файл `smeta.html` (MIT) — можно открыть и без приложения |
| **Прямая** | Ввели запись или неравенство — получили рисунок и обозначение |
| **Шестерёнка** (в правом верхнем углу) | Что показывать после решения (только ответ / ответ и шаги / всё раскрытое), способ решения, столбик, рисунок прямой |
| **Справочник** (в самом низу настроек) | Те самые 188 карточек: формулы, тождества, правила. Выбрали формулу — ввели числа — «Вычислить» — ответ крупно |

Выбор в настройках сделан **кружками-радиокнопками**: выбранный пункт
закрашивается синим, у остальных кружок остаётся пустым. Настройки
сохраняются в браузере (`localStorage`, ключ `gdzcalc.settings.v1`), поэтому
при следующем запуске приложение открывается в том же виде.

### `js/mathcore.js` — движок

* `compile`/`evaluate` — разбор выражения без `eval`: подразумеваемое умножение
  (`2a`, `3(x+1)`), запятая как десятичный разделитель, `−/×/÷/:`, `|x|`,
  `sqrt`, `abs`, `PI`, степени `^`.
* `fmt`, `fmtSmart`, `fmtPlain`, `asFraction` — вывод: `6,3`, `1/3`, `0,333…`.
* `solveEquation` — линейные уравнения точно, остальные — численно (бисекция).
* `solveSystem` — системы двух линейных уравнений методом Крамера.
* `Poly` — символьные многочлены: `expandExpression`, `polyToText` (порядок
  слагаемых как в учебнике), `checkIdentity` (символьно, с численной проверкой
  как запасным вариантом), `factorExpression` (общий множитель, `a²−b²`,
  `a³±b³`, полный квадрат, теорема Виета, группировка).
* `solveFormula(eq, unknown, known)` — выражает любую переменную из формулы
  (обратная задача: дано `S` и `b`, найти `a`).
* `substituteText` — подстановка чисел в формулу с человеческой записью.

### `js/formulas.js` — как добавить формулу

Каждая карточка — обычный объект в массиве `RAW`:

```js
{
  id: 'rect_area',           // уникальный, используется в ссылках
  ch: 'ch1', sec: '§ 1, п. 2', page: 12,
  kind: 'formula',           // formula | identity | rule | interval
  title: 'Площадь прямоугольника',
  display: 'S = a·b',        // как в учебнике
  eq: 'S = a*b',             // машинная запись для вычислителя
  vars: [
    ['a', 'длина a', 'см', 6],
    ['b', 'ширина b', 'см', 5],
    ['S', 'площадь S', 'см²', null],
  ],
  find: 'S',                 // что ищем по умолчанию (null — для правил)
  dom: [0, 1e6],             // область поиска неизвестной
  desc: '…', keywords: ['площад', 'прямоугольник'],
  example: '…',
}
```

`FORMULAS` собирается из `RAW`, `STATS` считает итоги, `formulaSearch(q)`
ищет по названию, записи, описанию и ключевым словам, `FORMULA_BY_ID` —
быстрый доступ по id. Тест `tests/smoke.mjs` автоматически проверяет, что
**каждая** формула решается при значениях по умолчанию, а каждое тождество
подтверждается символьно, — поэтому новая карточка сразу проходит проверку
или явно сообщает об ошибке.

Тождества (`kind: 'identity'`) задаются через `eq: 'L = R'`; в интерфейсе у них
две кнопки: «проверить» (подстановка чисел) и «раскрыть обе части» (символьное
раскрытие через `checkIdentity`).

### `js/intervals.js` — промежутки и рисунок

`parseInterval('[-2; 5)')` понимает:

* запись промежутка: `[a; b]`, `(a; b)`, `[a; b)`, `(a; b]`, `(-∞; b]`, `[a; +∞)`;
* неравенства: `x ⩾ 2`, `x < 3`, `x ≤ −1`, `x > 0`;
* двойные неравенства: `−2 ≤ x < 5`, `1 < x ≤ 4`;
* бесконечности в любой записи: `+∞`, `-∞`, `∞`, `бесконечность`.

`intersect(a, b)` и `union(a, b)` находят пересечение и объединение (для
непересекающихся промежутков объединение возвращается как два отрезка).

`numberLineSVG([{ interval, label, color }])` рисует числовую прямую в стиле
учебника (рис. 10—16): ось со стрелкой, засечки, **закрашенный кружок** для
включённого конца и **светлый кружок** для выключенного, выделенная линия над
осью и стрелки в бесконечность. Несколько промежутков рисуются на одной оси
разными цветами — видно пересечение. Это SVG без зависимостей: масштабируется,
печатается и работает в тёмной теме браузера.

### `smeta.html` — отдельный движок «Сметы»

Смета вынесена в **один самодостаточный файл** в корне репозитория — это
независимый MIT-проект внутри проекта: откройте `smeta.html` прямо в браузере
(работает даже через `file://`, без сети), в приложении он открывается во
вкладке «Смета» (iframe) и лежит внутри APK.

Что умеет:

* **переменные** — любое имя и любое выражение в значении (`цена * 1,2`);
  переменные считаются в порядке зависимостей (ссылка на объявленную ниже —
  не ошибка), циклы обнаруживаются и подсвечиваются;
* **ячейки** — тоже выражения, можно ссылаться на переменные и на **любые**
  ячейки своей строки по имени столбца (порядок столбцов не важен);
* **честные ошибки**: `1 / 0` в переменной не превращается в 0 — зависимая
  ячейка показывает ««a» не посчитана», итог столбца помечается `*` с
  подсказкой «не сложено: N ячеек с ошибками»;
* **«Всего»** по строкам и **«Итого»** по столбцам — считаются сами;
* **столбчатая диаграмма** по выбранному столбцу (canvas, перерисовывается
  при изменении размера окна/вкладки);
* **стрелки «что от чего зависит»** — связи между переменными и столбцами,
  добавляются и удаляются в интерфейсе (SVG);
* **вопросы словами**: «сколько сделали в первый день?», «какая численность?»,
  «сколько всего сделали?», «в каком дне больше всего сделали?»,
  «на сколько больше сделали во второй день, чем в первый?» — движок находит
  строку/столбец/переменную по словам вопроса (нормализация ё→е, ординалы
  «первый/первого/первом» → 1…10, основы слов) и **отвечает числом из таблицы**,
  подсвечивая нужную ячейку. Готовых ответов нет: всё считается из текущих
  данных. Если два столбца/строки подходят одинаково — смета спросит
  уточнение, а не угадает;
* **пресеты**: «Отчёт по дням» (строки — дни, столбцы — сделали/численность/брак)
  и «Смета покупки»;
* данные сохраняются в `localStorage` (ключ `gdzcalc.smeta.v1`).

Выражения — полноценные, с парсером (токены → AST → вычисление), без
`eval`/`Function`: `2 * цена`, `2(норма + 1)`, `2a`, `2^10`, `17 mod 5`,
`50 %` (в процентах), `1e3`, тысячи через пробел (`1 000 000`), десятичная
запятая или точка, функции `sqrt abs min max avg round floor ceil sin cos tg ln`.

Кнопки «− Столбец» / «− Строка» удаляют **столбец/строку в фокусе**
(а не последний), с подтверждением.

## Неравенства (вкладка «Неравенства»)

Это отдельный модуль `js/inequalities.js` — тоже разбор записи, без сети и
без «угадывания». Понимает:

| Запись | Ответ |
|---|---|
| `3x − 7 < 5x + 1` | `x > −4`, то есть `(−4; +∞)` |
| `−2 ⩽ 4 − 2x ⩽ 6` | `[−1; 3]` |
| `\|x − 2\| ⩽ 5` | `[−3; 7]` |
| `\|x − 2\| > 5` | `(−∞; −3) ∪ (7; +∞)` |
| `2x + 1 > 5; 3x − 4 ⩽ 8` | `(2; 4]` |
| `(x + 3)/2 ⩾ (2x − 1)/3` | `(−∞; 11]` |
| `A = [−3; 4), B = (1; 7]` + `A ∩ B` | `(1; 4)` |
| то же + `A ∪ B` | `[−3; 7]` |
| `M = (−∞; 3], N = [1; 6)` + `M \ N` | `(−∞; 1)` |

Что учтено:

* **точные дроби**: коэффициенты считаются как отношения целых, поэтому
  `(x + 3)/2 ⩾ (2x − 1)/3` решается через «умножим обе части на 6» и даёт
  ровно `x ⩽ 11`, а не `x ⩽ 10,999…`;
* **знак при делении на отрицательное** меняется на противоположный — это
  отдельной строкой в шагах;
* **модуль** раскрывается по правилу: `|A| ⩽ c` — это `−c ⩽ A ⩽ c`,
  `|A| > c` — это `A > c` или `A < −c`; частные случаи `c < 0` и `c = 0`
  разобраны отдельно;
* **двойное неравенство** решается как два обычных с общей частью;
* **система** — как пересечение решений всех строк;
* **текст, скопированный из PDF «по одной букве на строку»** (`3\nx\n−\n7\n<…`)
  склеивается обратно; подписи вида «Реши неравенство:» отбрасываются;
* вырожденные случаи дают честный ответ: `2x + 1 > 2x + 5` → «нет решений»,
  `2x + 1 < 2x + 5` → «x — любое число».

Функция `solveInequality(text)` возвращает `{ kind, intervals, answerText,
inequalityText, steps }`; промежутки — те же объекты, что и в
`js/intervals.js`, поэтому ответ сразу рисуется на числовой прямой.

Дроби пишите со скобками: `(x + 3)/2`. Запись `x + 3 / 2` математически
означает `x + 1,5`, и приложение считает именно так.

## Столбик

Включили галочку «Считать в столбик» — под клавиатурой появляется запись.
Деление рисуется **уголком**, как в тетради (с чертой, делителем справа и
ступеньками вычитания):

```
      768 │24
     −72  │──
      ──  │32
       48 │
      −48 │
       ── │
        0 │
```

Если нацело не делится, показывается остаток и проверка вида
`100 = 7 · 14 + 2`.

Остальные действия выглядят так:

```
  500          47          1234
 −137         ×36          +876
 ────         ────         ─────
  363          282          2110
               141
              ─────
               1692
```

`longArithmetic(a, b, op)` и `divideAngle(a, b)` из `js/inequalities.js`
возвращают `{ lines, value }` (у деления ещё `quotient` и `remainder`):
`lines` — строки одинаковой ширины для моноширинного шрифта, `value` — ответ.
Знаки, запятые (`12,5 × 4`) и отрицательные числа учитываются.

## Соглашения

* Десятичный разделитель на вводе — и запятая, и точка; на выводе — запятая.
* Минус в формулах — типографский `−`, в машинной записи — обычный `-`.
* Страницы указаны по бумажному учебнику; PDF-страница = страница + 1.
* Всё считается локально в браузере: ни запросов, ни зависимостей, ни отправки данных куда-либо.
